# Student Analysis Project

This is a simple Python project made to practice data analysis using Pandas and NumPy.

The project reads student data from a CSV file and performs basic analysis such as checking the dataset, finding average marks, counting pass and fail students, displaying top students, and comparing grades with study time.

## Tools Used

- Python
- Pandas
- NumPy
- Visual Studio Code
- Git and GitHub

## Files

- `student_analysis.py` - Main program for student data analysis
- `student-por.csv` - Student performance dataset
- `s_num.py` - Basic NumPy program for marks analysis
- `diss.py` - Another CSV data analysis practice program

## Features

- Reads CSV files using Pandas
- Shows the first rows of data
- Checks dataset information
- Shows statistical summary
- Finds average final grade
- Counts pass and fail students
- Displays top 5 students
- Compares average grades based on study time
- Performs simple NumPy calculations
